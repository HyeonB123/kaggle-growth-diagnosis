# Tableau Public 대시보드 제작 가이드

Streamlit 대시보드(`dashboard/app.py`)와 **같은 집계 데이터**(`dashboard/data/*.csv`)로 Tableau Public 버전을 만든다.
데이터 준비는 끝나 있으니 Tableau에서는 연결 → 시트 → 대시보드 조립 → 게시만 하면 된다.

## 0. 준비

| 항목 | 내용 |
|---|---|
| 프로그램 | Tableau Public (무료, Desktop Public Edition). 데이터 소스당 1,500만 행, 계정 저장 공간 10GB |
| 데이터 | `dashboard/data/*.csv` 10개, 모두 수십 ~ 수백 행 집계본 (유저 단위 데이터 없음) |
| 데이터 갱신 | `python scripts/06_dashboard_data.py` → Tableau에서 데이터 원본 새로 고침 → 다시 게시 |
| 주의 | Tableau Public에 올린 통합 문서와 데이터는 **공개**된다. 집계본만 올린다 |
| 글꼴 | 대시보드 전체: Apple SD Gothic Neo (Windows는 맑은 고딕). 서식 → 통합 문서에서 한 번에 지정 |

**색상 (Streamlit·노트북과 통일)** — 서식 → 통합 문서 → 사용자 지정 색 또는 각 마크 색에서 직접 입력

| 역할 | HEX |
|---|---|
| 주 지표, 창작 있음, 3년 이상 | `#6A55D0` |
| 황금기, 1 ~ 3년, 정밀도 | `#2B78D6` |
| 침체기, 90일 이내(신규) | `#E8912D` |
| 팀 합류만, 기준선, 정답 비율 | `#8C8C8C` |
| 연한 막대, 91일 ~ 1년 | `#B8B0E2` |
| 구간 음영 (황금기·침체기, 테스트 기간) | `#EFEDF8` |
| 배경 | `#FCFBF9` |

## 1. 데이터 연결

1. 데이터 → 새 데이터 원본 → 텍스트 파일 → `dashboard/data/growth_quarterly.csv`
2. 나머지 CSV도 각각 **별도 데이터 원본**으로 추가한다 (파일끼리 관계를 맺을 필요 없음, 시트마다 원본 하나)
3. 문자열로 읽힌 숫자 열이 있으면 데이터 원본 탭에서 형식을 숫자(십진수)로 바꾼다
4. 연결 방식은 **추출**(Tableau Public은 추출만 게시 가능)

## 2. 계산 필드

| 데이터 원본 | 이름 | 식 | 쓰는 곳 |
|---|---|---|---|
| growth_quarterly | `QAU 구분` | (피벗 사용) `qau_creators`, `qau_team_only`를 선택 → 우클릭 → 피벗 → 이름 `QAU 구분`, 값 `QAU 인원` | 누적 막대 |
| growth_quarterly | `시기 음영` | `IF [period] = "황금기" OR [period] = "침체기" THEN [period] END` | 음영 띠 (이중 축 막대) |
| growth_quarterly | `분기 순서` | `INDEX()` 또는 `q` 문자열 오름차순 정렬 | 가로축 정렬 |
| growth_trend | `판정 색` | `IF [정체 판정 (±5%)] = "정체" THEN "정체" ELSE "변화" END` | 표 강조 |
| growth_trend | `CI 폭` | `[CI 상한] - [CI 하한]` | 간트 막대(신뢰구간) |
| cohort_monthly | `지표 선택` | 매개변수 `[p_지표]` (문자열 목록: 90일 활성화 / 가입 당일 활동 / 90일 내 대회 참가 / 90일 내 창작 / 90일 내 가벼운 활동) | 매개변수 |
| cohort_monthly | `선택 지표 값` | `CASE [p_지표] WHEN "90일 활성화" THEN [activation_90d] WHEN "가입 당일 활동" THEN [same_day] WHEN "90일 내 대회 참가" THEN [team_90d] WHEN "90일 내 창작" THEN [creator_90d] ELSE [light_90d] END` | 월별 선 그래프 |
| model_monthly | `테스트 여부` | `[구분] = "테스트"` | 음영·색 |
| ab_params | `필요 인원(군당)` | 매개변수 `[p_효과]`(0.10 ~ 0.60, 0.05 간격) 사용: `2 * (1.96 + 0.8416)^2 * ([30일 제출 기준값] * (1 - [30일 제출 기준값]) + [30일 제출 기준값]*(1+[p_효과]) * (1 - [30일 제출 기준값]*(1+[p_효과]))) / ([30일 제출 기준값] * [p_효과])^2 / 2` | 표본 크기 계산기 (50 : 50, 근사식) |
| ab_params | `모집 기간(월)` | `2 * [필요 인원(군당)] / [월 평균 대상]` | 표본 크기 계산기 |

표본 크기 근사식은 Streamlit(arcsine 효과 크기)과 소수점 차이가 날 수 있다. +30%에서 둘 다 약 4개월.

## 3. 시트 (11개)

| # | 시트 이름 | 데이터 | 만드는 법 |
|---|---|---|---|
| 1 | KPI 카드 | growth_trend, growth_quarterly | 텍스트 표. "신규 가입자 연간 +27.9%", "QAU 연간 +0.5% (90% CI −0.9 ~ +1.9%) → 정체", "가입자 ×2.91", "QAU ×1.00" 4개를 큰 글씨로 |
| 2 | QAU 구성 | growth_quarterly (피벗) | 열 `q`, 행 `QAU 인원`, 색 `QAU 구분`(창작 있음 `#6A55D0`, 팀 합류만 `#8C8C8C`), 막대 누적. 황금기·침체기 구간은 **참조 구간**(분석 → 참조선 → 구간)으로 음영 |
| 3 | 신규 가입자 | growth_quarterly | 열 `q`, 행 `new_users`, 막대 `#B8B0E2` |
| 4 | QAU 연차 구성 | qau_tenure | 열 `q`, 행 `share`(백분율), 색 `tenure`, 막대 누적 100% |
| 5 | 정체 판정 | growth_trend | 행 `단위`, `지표`; 열 `연간 증가율`(원) + `CI 하한`~`CI 상한`(간트), ±5% 참조 구간 음영 |
| 6 | 90일 활성화율 추이 | growth_quarterly | 열 `q`, 행 `activation_rate`, 선 + 원 마커 (`#6A55D0`), 참조 구간 음영 |
| 7 | 가입 월별 지표 | cohort_monthly | 열 `month_index`, 행 `선택 지표 값`, 색 `period`(황금기 `#2B78D6`, 침체기 `#E8912D`), 선 + 마커. 매개변수 컨트롤 표시 |
| 8 | 퍼널·첫 활동·다음 단계 | funnel, first_activity, transitions | 시트 3개로 나눠 막대(그룹: 시기). 다음 단계 시트에 "가벼운 활동 시작 → 참여·창작" 막대를 주석으로 강조 |
| 9 | 모델 월별 성능 | model_monthly | 열 `cohort_month`, 행 `상위 10% 재현율`·`상위 10% 정밀도`·`정답 비율`(측정값 이름으로 색), 선 + 마커. 테스트 기간(2025-07 ~ 09) 참조 구간 |
| 10 | 분위별 lift | model_deciles | 열 `decile`, 행 `lift`, 1분위만 `#6A55D0`, 나머지 `#B8B0E2`, 레이블 "4.2배" 형식 |
| 11 | 표본 크기 계산기 | ab_params | 매개변수 `p_효과` 슬라이더 + `필요 인원(군당)`, `모집 기간(월)` 텍스트 |

**모든 시트 공통 서식** (프로젝트 차트 규칙)
- 제목: 왼쪽 위, 굵게, `핵심 메시지 — 부연 (기간, 정의)` 형식. 예: `QAU = 창작 있음 + 팀 합류만 — 정체는 두 흐름의 상쇄 (2017-Q1 ~ 2025-Q4)`
- 범례: 오른쪽 위, 가로 한 줄, 테두리 없음
- 격자: 가로선만 연하게, 세로선·위·오른쪽 테두리 없음
- 선 그래프에는 원 마커를 켠다 (마크 → 모양 또는 선 + 원 이중 축)
- 비율 차트 제목이나 범례에 표본 수(n) 표기
- 값 레이블은 다른 레이블·선과 겹치지 않게: 첫·끝·극값만 표시

## 4. 대시보드 (4개 + 스토리)

크기: 고정 1400 × 1000, 배경 `#FCFBF9`, 탭처럼 쓰려면 **스토리**로 4개를 묶는다.

| 대시보드 | 배치 (위 → 아래) | 필터·동작 |
|---|---|---|
| ① 성장 현황 | KPI 카드 / QAU 구성(전체 너비) / 신규 가입자 · QAU 연차 구성(반반) / 정체 판정 | 분기 범위 필터를 시트 2·3·4에 공통 적용 (필터 → 적용 대상 → 관련 데이터 원본) |
| ② 신규 유입 퍼널 | 90일 활성화율 추이 / 가입 월별 지표(매개변수) / 퍼널 · 첫 활동 · 다음 단계(3등분) / 결론 텍스트 1줄 | `p_지표` 매개변수 컨트롤 |
| ③ 예측 모델 모니터링 | KPI(최근 월 대상·PR-AUC·상위 10% 재현율·규칙 그룹 전환율) / 월별 성능 · 분위별 lift / 월별 표 | 없음 |
| ④ 실험 설계 | 실험군·대조군 정의 텍스트 / 기준값 KPI / 표본 크기 계산기 | `p_효과` 슬라이더 |

결론 문장(대시보드 하단 텍스트)
- ① "가입자는 연 28% 늘었지만 QAU는 ±2% 안 — 대회 참가만 하는 유저 감소를 창작 유저 증가가 상쇄"
- ② "참여 이후 단계는 그대로, 가벼운 활동 → 참여 연결만 절반으로 — 병목 후보는 입구"
- ③ "상위 10%에 전환자의 약 40%가 모인다 (무작위 대비 4배)"
- ④ "+30% 효과를 잡으려면 약 4개월 — 50 : 50 배정"

## 5. 게시

1. 파일 → Tableau Public에 저장 (Tableau Public 계정 로그인 필요, 무료)
2. 통합 문서 이름: `Kaggle 성장 정체 진단`
3. 게시 후 Tableau Public 프로필에서 "Allow others to download"는 꺼도 된다 (데이터는 집계본이라 켜도 무방)
4. 게시된 링크를 README의 대시보드 항목에 추가

## 6. Streamlit과 차이

| | Streamlit | Tableau Public |
|---|---|---|
| 실행 | `streamlit run dashboard/app.py` (또는 Streamlit Community Cloud 배포) | 링크로 바로 열람 |
| 강점 | 표본 크기·SRM 계산이 정확(statsmodels), 코드로 재현 | 채용 담당자가 설치 없이 보기 쉬움, 태블로 실무 역량 증명 |
| 데이터 | 같은 `dashboard/data/*.csv` | 같음 |
