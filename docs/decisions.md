## 문제 정의 (`notebooks/01_problem_definition.ipynb`)

| 날짜 | 결정 | 근거 |
|---|---|---|
| 2026-10-21 | **QAU = 분기에 참여·창작 활동을 1회 이상 한 전체 유저** (가입 시점 무관). 참여 = 팀 합류(대회 참가), 창작 = 노트북 버전·공개, 제출, 포럼 글, 데이터셋·모델 버전, 태스크. 투표·팔로우·반응 제외 | 흔적을 남기는 행동만 기록되는 데이터라 방문·조회는 측정 불가. 가벼운 반응은 참여 의지의 신호로 약함 |
| 2026-10-21 | QAU를 **창작 있음 / 팀 합류만** 으로 분해해서 함께 보고 | 2020 → 2024-25 QAU ×1.00이지만 팀 합류만 ×0.82, 창작 있음 ×1.45. 정체는 반대 방향 두 흐름의 상쇄 |
| 2026-10-21 | QAU를 **가입 연차**(90일 이내 / 1년 / 1~3년 / 3년 이상)로도 분해 | 신규(90일 이내) ×0.82, 3년 이상 ×1.72. 비중 37% → 30%, 13% → 22%. QAU가 오래된 유저에 기대는 구조 → 신규 공급 감소가 이어지면 QAU 하락 위험 |
| 2026-10-21 | "가입자 대비 활성 비율"(QAU / 당분기 신규 가입자) 사용 안 함 → **코호트 90일 활성화율**로 대체 | 분자는 전체 유저, 분모는 신규 가입자라 비율이 아님. 가입자가 늘면 행동 변화 없이도 기계적으로 하락 |
| 2026-10-21 | **정체 판정 = 동등성 검정(TOST)**: `log(Y) ~ 연 + 분기 더미`, HAC 표준오차, 연간 증가율 90% CI가 ±5% 안이면 정체 | "추세가 유의하지 않음"은 정체의 증거가 아님. 마진 5% = 가입자 성장률(연 28%)의 1/5 미만. CI가 ±2% 안이라 마진 선택에 결론이 흔들리지 않음 |
| 2026-10-21 | 성장은 **지수형(log) 모형**으로 요약 | 신규 가입자 MAPE 지수형 4.1% vs 직선형 6.2%, 직선형 잔차에 체계적 패턴(+6% → −6% → +1%) |
| 2026-10-21 | 추세 분석 기간 2020-Q1 ~ 2025-Q4 | 2016년부터 보면 성장률 자체가 감속해서 일정 비율 가정이 깨짐 |
| 2026-10-21 | 헤드라인은 분기(QAU), **MAU로 견고성 확인** | 재활동 간격: 반복 유저 간격 중앙값이 30일 이내 63.5%, 90일 이내 78.5%. 활동일 기준 복귀의 84%가 30일 이내라 MAU도 근거 있음 → 둘 다 계산, MAU도 정체(연 +0.6%, 90% CI −0.6 ~ +1.7%). 분기는 코호트 관찰 기간(90일)과 맞음 |

## 가설 (판정 기준을 검증 전에 고정)

| 날짜 | 결정 | 근거 |
|---|---|---|
| 2026-10-21 | **H1 유입 질**: 침체기 신규 가입자의 90일 활성화율이 황금기보다 낮다. 상대 차이가 기준(5%, 10% 둘 다) 밖이고 95% CI도 기준 밖이면 지지, 기준 안이면 기각 | n이 수백만이라 p값은 항상 0 → 실무적 크기로 판정. 기준 두 개로 민감도 확인 |
| 2026-10-21 | **H2 활성화 병목**: 비-D 참여(팀 합류, 노트북 작성)로 시작한 유저의 90일 내 D 전환율이 침체기에 낮다. 판정 기준은 H1과 같음 | 문턱 없는 넓은 정의를 주 분석으로 사용 |
| 2026-10-21 | H2 견고성: 시도자(C그룹) 정의 = 팀 합류 OR 노트북 최종 50줄 이상 OR 수정 4회 이상, 문턱 30·100줄 / 2·8회로 바꿔 재확인 | 50줄은 제출률이 약 2배로 뛰는 지점(51~100줄 9.26%)이지만 제출(= D)로 정한 문턱이라 주 정의로 쓰면 순환 논리. 수정 횟수는 뚜렷한 꺾임 없음 |
| 2026-10-21 | H2 결과는 선택 편향과 함께 해석 | 참여 시작자 자체가 침체기에 더 걸러진 집단이라 조건부 전환율이 높게 나올 수 있음 |
