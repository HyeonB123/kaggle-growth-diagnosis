# A/B 테스트 설계서 (요약): 진행 중 대회 추천

계산과 근거: [`notebooks/06_ab_test_design.ipynb`](../notebooks/06_ab_test_design.ipynb)

## 왜 실험인가

관찰 데이터에서 진행 중 대회에 참가한 신규 유저의 90일 D 전환율(9.4%)은 끝난 대회에만 참가한 유저(3.0%)의 3배다.
하지만 원래 의지가 큰 사람이 진행 중 대회를 골랐을 수 있다(자기 선택). **추천으로 이 차이를 만들 수 있는지**는 무작위 배정으로만 알 수 있다.

- 인과 질문: 평균 처치 효과 ATE = E[Y(1) − Y(0)]
  - Y(1): 추천을 받았을 때 30일 안에 대회에 제출하는가
  - Y(0): 추천을 받지 않았을 때 30일 안에 대회에 제출하는가

## 설계

| 항목 | 내용 |
|---|---|
| **대상** | 가입 후 D+14 시점에 아래 조건을 모두 만족하는 유저. 월 약 6,100명 (D+14 예측 모델 대상의 33%) |
| ├ 포함 | 대회에 참가했고, 참가한 대회가 **모두 마감된 대회** (데이터를 받으러 온 유저) |
| └ 제외 | D 활동이 이미 있음 / 노트북 작성자(규칙 그룹) / 대회 참가 10개 초과(자동화 의심) / 메일 수신 거부 / 다른 온보딩 실험에 배정됨 |
| **실험군** (50%) | D+15 오전 9시(현지 시각)에 "지금 참가할 수 있는 대회 3개" 메일 1통 + 사이트 알림 1회(D+15 ~ D+21) |
| └ 추천 규칙 | 마감까지 30일 이상 남은 대회만. Playground Series 1개 + 참가했던 대회와 태그가 겹치는 진행 중 대회 2개 (없으면 참가 팀 수 상위) |
| **대조군** (50%) | 아무것도 보내지 않음. 평소 시스템 메일만 |
| **배정** | 유저 단위. D+14 모델 점수 10분위 안에서 `hash(UserId + 실험이름) mod 100 < 50` → 실험군. 처치 전에 배정 |
| **주 지표** | 처치 후 30일(D+15 ~ D+44) 대회 제출. 기준값 1.56% |
| **보조 지표** (Holm 보정) | D+15 ~ D+90 D 활동 (2.97%), 30일 안 진행 중 대회 참가 |
| **가드레일** | 메일 수신 거부율: 실험군 − 대조군 +0.5%p 초과 시 중단 |
| | 90일 QAU 활동: 비열등성 (실험군/대조군 95% CI 하한 > 0.95) |
| **추정 대상** | 주: ITT (배정 기준). 보조: CACE = ITT ÷ 메일 열람률 (배정을 도구변수로) |
| **표본·기간** | α = 0.05, 검정력 80% 기준. +30% 효과(1.56% → 2.03%)는 군당 1.26만 명, **약 4개월 모집 + 30일 관찰** |
| | +20% 효과는 약 9개월. 80 : 20 배정은 같은 검정력에 1.6배 오래 걸림 |
| **분석** | 층(점수 10분위)을 반영한 추정 (A/A 시뮬레이션 거짓 양성 5.0%). 단순 z검정은 3.5%로 보수적 |
| | 모델 점수 CUPED 보정 (분산 감소 2.5%로 작음) |
| | 사전 지정 이질성 분석 1개: 점수 3분위별 효과 |
| **중간 확인** | 가드레일과 표본 비율 불일치(SRM)만. 주 지표는 정한 인원이 모일 때까지 보지 않음 |

## 의사결정 규칙

| 결과 | 결정 |
|---|---|
| 주 지표 95% CI 하한 > 0, 가드레일 통과 | 대상 전체로 확대. 대조군 5%는 남겨 효과를 계속 측정 |
| 점수 상위 구간에서만 효과 | 모델로 대상을 골라 상위 구간에만 적용 |
| CI가 0을 포함 | 보류. 3군 설계(대조군 = 일반 안내 메일)나 다른 처치로 이동 |
| 가드레일 실패 | 즉시 중단 |

## 인과 가정과 대응

| 가정 / 위협 | 대응 |
|---|---|
| 교환 가능성 | 해시 배정, 점수 층화, 공변량 균형(표준화 평균차 < 0.1), SRM 점검 |
| SUTVA: 간섭 없음 | 신규 유저끼리 팀을 이루는 경우는 드묾. 대조군의 실험군 팀 합류를 모니터링 |
| SUTVA: 처치가 하나 | 추천 규칙을 고정해 "규칙에 따른 추천" 전체를 하나의 처치로 정의 |
| 비순응 (메일 미열람) | ITT를 주 분석으로. 연 사람끼리만 비교하지 않음 |
| 오염 (동시 캠페인) | 다른 온보딩 실험에서 제외, 일반 메일은 두 군 동일 |
| 외적 타당성 | 4개월 연속 모집으로 대회 일정·계절을 두 군에 고르게. 확대 후에도 대조군 유지 |
| 메일 효과 vs 내용 효과 | 2군 설계로는 구분 불가 → 효과가 있으면 3군 후속 실험 |
