# Kaggle 성장 정체 진단: "가입자 3배 증가, QAU 정체"의 원인을 찾아서

Meta Kaggle 공개 데이터로 **가입자는 빠르게 늘었는데 활성 유저(QAU)는 왜 그대로인가**를 진단하고,
가입 14일 차 행동으로 90일 안에 핵심 창작 활동을 할 유저를 예측하는 모델(Early QAU Predictor)을 만든다.

- 데이터: [Meta Kaggle](https://www.kaggle.com/datasets/kaggle/meta-kaggle) (31개 테이블 중 20개 사용, MySQL 적재, 2026-03-27까지)
- 결정과 근거: [`docs/decisions.md`](docs/decisions.md)

## 문제 정의

2020 → 2025년 분기 신규 가입자는 **연 28%** 성장했지만, QAU는 **연 +0.5% (90% CI −0.9 ~ +1.9%)** 로 동등성 검정 기준 정체다.
늘어난 가입자가 왜 활성 유저로 이어지지 않는가?

| 용어 | 정의 |
|---|---|
| QAU | 분기에 **참여·창작 활동**을 1회 이상 한 전체 유저. 참여 = 팀 합류(대회 참가), 창작 = 노트북 버전·공개, 대회 제출, 포럼 글, 데이터셋·모델 버전, 태스크. 투표·팔로우·반응은 제외 |
| D 활동 (핵심 창작) | 노트북 공개, 대회 제출(팀 단위), 포럼 글, 데이터셋 버전·태스크, 모델 버전 |
| 90일 활성화율 | 가입 코호트 중 가입 후 90일 안에 QAU 활동을 시작한 비율 |
| 코호트 | 황금기 2020-Q1 ~ Q4 (204만 명) / 침체기 2024-Q3 ~ 2025-Q2 (594만 명) |

## 가설 (판정 기준은 검증 전에 고정, `docs/decisions.md`)

| 가설 | 주 지표 | 판정 |
|---|---|---|
| H1 유입 질: 침체기 가입자는 참여를 덜 시작한다 | 90일 활성화율 | 상대 차이 5%·10% 기준 밖이면 지지 |
| H2 활성화 병목: 참여를 시작해도 창작(D)까지 덜 간다 | 비-D 참여 시작자의 90일 내 D 전환율 | 같은 기준. 시도자(C그룹) 정의로 견고성 확인 |

## 예측 모델 (1차)

| 항목 | 내용 |
|---|---|
| 예측 대상 | 4분기 코호트 중 D+14까지 활동이 있고 아직 D 활동은 없는 유저 443,139명 |
| 정답 | D+15 ~ D+90에 D 활동 (양성 4.25%) |
| 결과 | 노트북 계열 피처 7개(라벨의 선행 단계) 제거 후 앙상블 PR-AUC 0.2899 (valid) / 약 0.27 (test), 랜덤 대비 약 6.4배 |
